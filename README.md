# 🏥 Hospital Emergency Room Dashboard

## 📊 Project Overview

This project presents an Excel-based Hospital Emergency Room Dashboard
designed to analyze patient information and emergency room performance.

The dashboard provides an interactive monthly report with key insights
about patient admissions, waiting time, satisfaction score, gender,
age groups, and department referrals.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze the number of patients visiting the emergency room
- Compare admitted and non-admitted patients
- Analyze patient waiting time
- Understand patient satisfaction
- Analyze patients by gender
- Analyze patient age groups
- Identify department referral patterns
- Provide a monthly view of emergency room performance

---

## 📌 Dashboard KPIs

The dashboard includes the following key metrics:

- Total Patients
- Average Wait Time
- Patient Satisfaction Score
- Patient Attend Status
- Gender-wise Patient Analysis
- Patient Age Group Analysis
- Department Referral Analysis
- Admission Status
---
## 📈 Dashboard Analysis
### 1. Patient Analysis
The dashboard displays the total number of patients and their
distribution across different age groups.
### 2. Admission Status
Patients are divided into:
- Admitted
- Not Admitted
### 3. Waiting Time
The dashboard shows the average waiting time of patients in the
emergency room.
### 4. Patient Satisfaction
The dashboard includes the average patient satisfaction score.
### 5. Gender Analysis
Patients are analyzed based on:
- Female
- Male
### 6. Age Group Analysis
Patients are grouped into different age categories:
- 0–9
- 10–19
- 20–29
- 30–39
- 40–49
- 50–59
- 60–69
- 70–79
### 7. Department Referral
The dashboard analyzes the number of patients referred to different
departments such as:
- General Practice
- Orthopedics
- Physiotherapy
- Gastroenterology
- Cardiology
- Neurology
- Renal
